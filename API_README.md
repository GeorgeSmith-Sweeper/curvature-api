# Curvature API & Web Interface

A modern REST API and web interface for exploring curvature road data with Google Maps integration.

## 🏗️ What We Built

This adds a new interactive layer on top of the curvature project:

- **REST API** (`api/server.py`) - FastAPI-based backend for querying road data
- **Web Interface** (`web/static/`) - Interactive Google Maps application
- **Real-time Filtering** - Search by curvature, surface type, and more
- **Visual Map Display** - Color-coded roads by "twistiness"

## 📁 Project Structure

## 🚀 Quick Start

### 1. Install Python Dependencies

```bash
cd api
pip install -r requirements.txt
```

**What this installs:**
- `fastapi` - Modern web framework
- `uvicorn` - ASGI server to run FastAPI
- `msgpack` - For reading curvature data files

### 2. Get a Google Maps API Key

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create a new project (or use existing)
3. Enable the **Maps JavaScript API**
4. Create credentials → API Key
5. Copy your API key

### 3. Add Your API Key

Edit `web/static/index.html` and replace `YOUR_API_KEY`:

```html
<script async defer
    src="https://maps.googleapis.com/maps/api/js?key=YOUR_ACTUAL_API_KEY_HERE&callback=initMap">
</script>
```

### 4. Generate Curvature Data

If you don't have data yet, process an OSM file:

```bash
# Download data (example: Vermont)
wget http://download.geofabrik.de/north-america/us/vermont-latest.osm.pbf

# Process it (this creates vermont.msgpack)
./processing_chains/adams_default.sh -v vermont-latest.osm.pbf -t /tmp -r

# The processed data will be at: /tmp/vermont-latest.msgpack
```

**For your area (Catskills/NY):**
```bash
wget http://download.geofabrik.de/north-america/us/new-york-latest.osm.pbf
./processing_chains/adams_default.sh -v new-york-latest.osm.pbf -t /tmp -r
```

### 5. Start the API Server

```bash
cd api
python server.py
```

You should see:
```
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
INFO:     Started reloader process
```

### 6. Open the Web Interface

Open your browser to:
```
http://localhost:8000/static/index.html
```

## 📖 How to Use

### Step 1: Load Data
1. Enter the path to your `.msgpack` file (e.g., `/tmp/vermont-latest.msgpack`)
2. Click "Load Data"
3. Wait for success message

### Step 2: Search & Filter
1. Adjust **Minimum Curvature** slider (300 = mildly curvy, 2000+ = very twisty)
2. Select **Surface Type** (paved, unpaved, or all)
3. Set **Max Results** limit
4. Click "Search Roads"

### Step 3: Explore
- Roads appear on the map, color-coded by curvature:
  - 🟡 **Yellow** - Mild curves (300-600)
  - 🟠 **Orange** - Moderate curves (600-1000)
  - 🔴 **Red** - Very curvy (1000-2000)
  - 🟣 **Purple** - Extremely twisty (2000+)

- Click any road on the map to see details
- Click any road in the sidebar list to zoom to it

## 🔌 API Endpoints

The API provides these endpoints:

### `GET /`
API information and available endpoints.

### `POST /data/load?filepath=<path>`
Load a msgpack file into memory.

**Example:**
```bash
curl -X POST "http://localhost:8000/data/load?filepath=/tmp/vermont-latest.msgpack"
```

### `GET /roads/geojson`
Get roads as GeoJSON for map display.

**Parameters:**
- `min_curvature` (default: 300) - Minimum curvature score
- `max_curvature` (optional) - Maximum curvature score
- `surface` (optional) - Filter by surface: `paved`, `unpaved`, `unknown`
- `limit` (default: 100) - Maximum results

**Example:**
```bash
curl "http://localhost:8000/roads/geojson?min_curvature=1000&surface=paved&limit=50"
```

**Response:**
```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "LineString",
        "coordinates": [[-72.5, 43.8], [-72.51, 43.81], ...]
      },
      "properties": {
        "name": "Route 100",
        "curvature": 1250.5,
        "length_km": 15.3,
        "length_mi": 9.5,
        "surface": "paved"
      }
    }
  ],
  "metadata": {
    "total_collections": 5000,
    "filtered_count": 50
  }
}
```

### `GET /roads`
Get roads as simple JSON (without full geometry).

**Example:**
```bash
curl "http://localhost:8000/roads?min_curvature=1000&limit=10"
```

### `GET /health`
Health check - useful for monitoring.

### `GET /docs`
Interactive API documentation (automatically generated by FastAPI).

Visit: http://localhost:8000/docs

## 🛠️ Development Tips

### Auto-Reload on Code Changes

The server runs with `reload=True`, so it automatically restarts when you edit `server.py`. Just save and refresh your browser!

### Viewing Logs

The terminal running `python server.py` shows all requests:
```
INFO:     127.0.0.1:54321 - "GET /roads/geojson?min_curvature=1000 HTTP/1.1" 200 OK
```

### Python Debugging

Add print statements or use `import pdb; pdb.set_trace()` for debugging:

```python
@app.get("/roads/geojson")
async def get_roads_geojson(...):
    print(f"Searching with min_curvature: {min_curvature}")  # Debug output
    # ... rest of function
```

### JavaScript Debugging

Open browser DevTools (F12) and check the Console tab for:
- API responses: `console.log('Data loaded:', data)`
- Errors: Shown in red
- Network tab: See all API requests

## 🚧 Known Limitations & TODOs

1. **API Key Exposure**: The Google Maps API key is in the HTML. For production, restrict it to your domain in Google Cloud Console.

2. **Memory Usage**: Data is loaded into memory. For large regions (like full USA), consider:
   - Using a PostGIS database instead
   - Implementing pagination
   - Loading data on-demand by bounding box

3. **No Persistent Storage**: Data needs to be reloaded on server restart. Future: auto-load on startup.

4. **No User Authentication**: Currently open access. Add auth if deploying publicly.

5. **No LLM Integration Yet**: The framework is ready for Claude integration. Next step: add conversational search!

## 📚 Understanding the Code

### How the API Works (server.py)

```python
# 1. FastAPI creates the web server
app = FastAPI()

# 2. Decorators map URLs to functions
@app.get("/roads/geojson")  # URL: /roads/geojson
async def get_roads_geojson():  # This function handles it
    return {...}  # Response sent to browser

# 3. The function:
#    - Reads parameters from URL (?min_curvature=1000)
#    - Filters data
#    - Converts to GeoJSON
#    - Returns JSON response
```

### How the Web Interface Works (app.js)

```javascript
// 1. User clicks "Search Roads"
function searchRoads() {
    // 2. JavaScript calls API
    fetch('/roads/geojson?min_curvature=1000')
        // 3. Get response
        .then(response => response.json())
        // 4. Display on map
        .then(data => displayRoadsOnMap(data));
}

// 5. Google Maps renders the roads
function displayRoadsOnMap(geojson) {
    dataLayer.addGeoJson(geojson);  // Magic!
}
```

### Data Flow

```
User → Web Interface → API Server → Curvature Data → API Response → Map Display
      (JavaScript)     (Python)      (.msgpack)      (GeoJSON)      (Google Maps)
```

## 🐛 Troubleshooting

### "ModuleNotFoundError: No module named 'fastapi'"
→ Run `pip install -r api/requirements.txt`

### "FileNotFoundError: Data file not found"
→ Check the filepath - use absolute path like `/tmp/vermont-latest.msgpack`

### Map shows gray box
→ Check browser console (F12) for API key errors. Make sure you added your Google Maps API key.

### "No data loaded" error
→ You must call `/data/load` first before searching. Use the "Load Data" button in the UI.

### Server won't start - "Address already in use"
→ Port 8000 is taken. Either kill the other process or change the port in `server.py`:
```python
uvicorn.run("server:app", host="0.0.0.0", port=8001)  # Use 8001 instead
```

### Roads don't appear on map
→ Check:
1. Console for JavaScript errors (F12)
2. Network tab - is the API call successful?
3. Does the GeoJSON have features? Visit `/roads/geojson?min_curvature=300&limit=10` directly
